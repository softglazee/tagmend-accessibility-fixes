Accessibility fixes for theme, page builder and WooCommerce HTML: common WCAG failures repaired on your server. No overlay. Preview each fix.

== Description ==

Tagmend adds an Accessibility Fixes menu to the WordPress admin. This development version adds missing image alt text from the Media Library, gives images inside named links and buttons an empty alt, hides decorative icons inside named links and buttons, and repairs untitled iframes, a missing or malformed page language and viewport tags that block zooming. Filling empty alt text from the Media Library and using the product name for WooCommerce product images are available and start Off. Each fix has its own Off, Preview and Live setting; nothing changes for visitors until a fix is set to Live.
