Accessibility fixes for theme, page builder and WooCommerce HTML: common WCAG failures repaired on your server. No overlay. Preview each fix.

== Description ==

Tagmend adds an Accessibility Fixes menu to the WordPress admin. This development version repairs untitled iframes, a missing or malformed page language and viewport tags that block zooming. Each fix has its own Off, Preview and Live setting; nothing changes for visitors until a fix is set to Live.
