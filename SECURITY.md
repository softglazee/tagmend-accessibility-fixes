# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting a vulnerability

Please do not report security problems in public issues.

Report them privately instead, in either of these ways:

- GitHub's private vulnerability reporting: the **Security** tab of this repository, then **Report a vulnerability**.
- Email: azhar@softglaze.com

Include the plugin version, the WordPress and PHP versions, the steps to reproduce the problem, and what an attacker could do with it. If a page's HTML is needed to show the problem, include the smallest page that does, rather than a link to a live site.

You will get a reply by email. When a fix is released, the changelog can credit you if you wish.
